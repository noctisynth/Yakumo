# 用户头像接入验证

文档编号：CHECK-004。状态：Verified within stated scope。更新：2026-10-15。
规范：SPEC-004；事实：FACT-006、EV-17。测试数据及图片均为合成值。

## 实现范围

按新版 data.imageRouteUrl 读取展示头像，独立于旧版 headImageUrl、H5 缓存键和人脸照片。
原生边界使用所属账号不可变会话，为无业务 Query 的当前用户信息 GET 生成签名；
未扩展为通用运动签名、配置封包或写入接口。头像读取和图片失败不改变核心登录或切换结果。
按账号加密缓存图片 data URL，兼容旧会话缺少头像字段；首次读取当前账号和切换时每次
运行最多尝试一次，重新登录重新读取。过期会话不发起头像请求，无循环后台重试。
界面使用 Radix Avatar 的 Image 和 Fallback，本地组件遵循 shadcn 的组合方式与 Tailwind 样式。
未扩大 WebView 的远程图片或连接 CSP，图片下载不附加学校身份请求头或 Referer。

## 验证结果

- 完整工程检查通过：Biome、应用及脚本类型、版本一致性、前端生产构建、Rust 格式及 Clippy。
- 十七项常规 Rust 测试通过；系统密钥库测试默认忽略，本次在 Windows 独立运行通过并清理临时条目。
- 签名派生对照 FACT-002 的合成向量，无业务 Query 的完整签名还与独立 Node.js 加密实现对照。
- 回环 HTTP 模拟验证 GET 路由、Bearer、school、Cookie、timestamp 和 sign；图片请求未携带
  Authorization、Cookie、school、timestamp、sign 或 Referer。
- imageRouteUrl 空字符串、null 和缺失正常返回无头像，不回退读取旧字段；相对地址、协议相对
  地址得到规范化。拒绝不支持的协议、带凭据 URL、私网目的地址、重定向、非图片和超限响应。
- 测试覆盖账号头像隔离、缓存恢复及移除、旧数据兼容、头像失败仍可登录、每次运行只尝试一次，
  以及过期会话不产生头像请求。
- 浏览器验证 Avatar 加载合成 PNG，缺失、损坏及未登录状态显示占位；切换到无头像账号不会
  保留前一个账号的图片。菜单键盘焦点返回、360px 布局通过，无页面运行错误或外部请求。
- 检查桌面截图中卡片和菜单的图片、占位及对齐；合成图片不属于真实用户资料。
- Windows x64 Tauri debug 无安装包构建通过；首次被现有进程占用，用户解除占用后复用缓存完成。
- Semifold minor/feat changeset 已登记，配置检查及版本计划通过；不消费 changeset、不发布软件。

## 验证限制

没有使用或迁移私人会话，没有对真实账号执行读取、头像上传或资料修改。
历史空头像响应不等于真实非空头像地址已完成在线验证；非空地址形态继续保持兼容边界。
生产图片必须是可公开访问且无需 Bearer 的 PNG、JPEG、GIF 或 WebP，最大 256 KiB；
需要鉴权、重定向或超出限制时显示占位。下载保留 TLS 验证，不禁用证书校验。
新增原生实现仅验证 Windows x64，其他系统构建和凭据库运行情况不继承历史基线。


## EV-18 更换头像与缓存刷新验证

原生离线测试覆盖固定 H5 appId、原始 Base64 加号的独立 AES 对照向量、单层表单编码、
Authorization 与签名、成功绑定响应、业务拒绝及非 JSON 的结果不确定分类；不追加旧保存路由。
283184 字节合成 PNG 可缓存，超出 2 MiB 及非栅格图片仍拒绝。显式身份刷新可替换并持久化
缓存，存储失败保持原快照，重新登录后的迟到响应拒绝回写。
浏览器合成账号在 360 与 1440 像素通过选图不上传、取消不上传、确认上传、504 像素居中预览、
刷新及不确定错误就近展示；未调用真实学校写入接口。Android 选图及原生界面仍待真机验收。
