# 多账号验证

文档编号：CHECK-003。状态：Verified within stated scope。更新：2026-10-14。
规范：SPEC-004；实施清单：TASK-002。所有账号及令牌测试数据均为合成值。

## 功能与边界

实现桌面多账号登录、当前账号切换、同服务端身份重新登录更新、本地移除及过期提示。
原生登录按 EV-03 获取 RSA 公钥、使用 PKCS#1 v1.5 密码加密及 Query 参数，随后获取原始 appId。
Basic 兼容值与新版静态拦截器核对；没有读取、解密或迁移任何私人会话。
目前只支持首校 swpu；每次密码登录要求明确确认已验证 HTTP 入口的传输风险。
未执行真实账号登录、刷新、学校业务读取或运动上传，不新增服务端接受性结论。
