# 学校读取与数据大盘验证

文档编号：CHECK-006。状态：Verified within stated scope。更新：2026-10-15。
规范：SPEC-006；协议及事实：SPEC-005、FACT-002、FACT-004。

## 离线接口和状态验证

完整检查通过：Biome、应用及脚本类型、版本一致性、前端生产构建、stable Rust 格式和 Clippy。
Rust 常规测试 24 项通过，1 项系统密钥库测试默认忽略；前端及发布脚本 8 项测试、53 个断言通过。
CI 质量工作流新增大盘状态测试。
Windows x64 Tauri debug 应用完整构建通过，未制作安装包；工作流通过 actionlint 检查。

本地 HTTP 模拟覆盖五条固定 GET 路由、Bearer 及签名、配置请求封包和响应解密，校验手动坐标、
运动类型与公开证书 MD5。另验证字符串业务码、字符串数值、null、HTML、HTTP 401、业务升级拒绝、
非法输入及敏感字段清理。账号读取使用不可变会话快照，网络期间不持有账号锁。
状态测试覆盖迟到账号响应丢弃、筛选请求顺序、独立资源失败和同查询刷新失败时保留已知值。

公开兼容材料核对：静态 JNI 绑定 Transform.a(Context) 对应 native_auth_5dm，使用公开证书
和建模 JNI 执行原生 MD5 方法，与 Rust 证书 DER 摘要一致。仅使用公开材料；不读取私人会话。
此结果区别于 v 的 SHA-256 指纹链，不代表替代客户端通过服务端设备或版本校验。

## 页面验证

使用本地页面、合成账号及模拟原生命令完成浏览器交互检查，无外部网络请求、控制台或页面错误。
覆盖登录成功进入大盘、累计和周里程、学期 null 显示未知、各类运动汇总、日期图、记录详情及
avgspeed 字段、状态和日期筛选、日期分组翻页、空记录、显式输入坐标读取配置、部分失败保留数据。
在旧账号请求未完成时切换账号，确认筛选重置且旧响应不覆盖新账号。360 像素窄屏无横向溢出，
使用双列统计与记录卡片；桌面使用统计卡、汇总和图表、记录表及折叠配置区。

## 范围限制

本轮未访问真实学校服务、开始运动或上传；服务端实际兼容性、业务口径与目标平台运行需独立验证。
配置仅支持已有证据的 runType=1，使用历史观察的 2.0.22/20220 兼容参数；版本拒绝明确反馈。
坐标由用户输入且不持久化；未知阈值和开关按原值显示。列表日期页不冒充普通分页，不编造总页数。
不从累计次数或未知学期目标推断达标，不将本地模拟响应作为真实有效记录证明。

显式查询定位复验（2026-10-15）：使用合成浏览器定位与 Android 插件命令，验证进入页面零定位与
零权限调用、点击后单次读取、仅回填不查询、用户确认后发送、拒绝保留坐标和手动输入继续查询。
360 与 1440 像素无横向溢出。未读取本机真实位置或向学校发送坐标。前端生产构建通过；
Android 原生权限弹窗及实际设备定位仍需云端或真机验证，不以插件模拟结果代替平台验收。
