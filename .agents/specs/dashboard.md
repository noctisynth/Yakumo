# 学校数据与跑步大盘

文档编号：SPEC-006。状态：Active。更新：2026-10-15。
依据：用户授权第二部分；协议：SPEC-005；事实：FACT-002、FACT-004。

密码登录成功后自动进入大盘；首页自动并行读取汇总、统计及有效记录。大盘展示累计与本周、学期里程、各运动类型
服务端有效次数及日期里程分布。按 SPEC-007 将记录列表、筛选和日期分组迁至独立运动记录页，
配置迁至独立学校配置页，均由侧栏进入；详情返回运动记录页。
各数据块独立加载、错误和更新时间，不用零替代未知值；刷新失败保留旧值并标明错误。
切换账号立即清空旧数据，响应以账号和请求序号校验；过期会话提示重新登录，不自动刷新令牌。
详情只读展示返回状态、备注、距离、时长、步数及配速，不从客户端字段推断服务器有效性。

配置请求由用户确认表单经纬度后提交，首期仅使用已有证据的 runType=1。允许用户主动点击获取一次
当前位置，点击前不检查或请求定位权限、不读取设备位置；拒绝或失败仍可手动输入。不读取历史坐标，
不持久化输入。使用已观察的 2.0.22/20220 兼容参数，brand/model 明确为替代客户端，
signatureMD5 通过公开证书和 Transform.a 的原生绑定离线核对，与 v 的 SHA-256 链分开。
服务拒绝、升级要求或当日限制分别反馈，不伪造配置成功或自动更换设备证明。

原生命令只允许固定学校的五类读取，校验账号、会话有效期、筛选、页码、坐标及记录标识。
网络期间释放账号锁，令牌快照不进入前端；不执行开始运动、上传或重传。
HTTP、超时、传输、业务拒绝、非 JSON、解密及结构错误分别返回固定消息，不回显请求或响应秘密。
前端收到的业务数据剔除令牌、设备环境和人脸照片等敏感协议字段，未知正常字段保留。
数字、字符串数值及 null 按字段读取，未知状态显示原值；列表与统计不强行视为同一口径。
记录日期使用服务端提供值；日期分组页不宣称是普通记录页，未知分页总数不编造。
数据仅保留本次运行内存，UI 使用 Tailwind、shadcn 组件与响应式布局；窄屏使用双列指标及记录卡片。

验收覆盖固定 GET 路由和签名、配置封包及解密、部分失败、null、非 JSON、切换及迟到响应，
并使用合成数据验证大盘、筛选、详情、坐标输入及窄屏。真实服务测试独立记录。

## 显式获取查询位置

定位与读取配置为两个独立动作：获取位置只回填本次表单，用户点击读取配置才将坐标发送学校。
进入页面、切换账号、刷新和重试学校请求均不触发定位；不调用持续定位或后台位置服务。
Android 使用官方定位插件，仅开放检查权限、请求权限和单次读取命令；优先请求大致位置。
桌面和浏览器使用系统 WebView 的单次定位接口，系统不支持或权限拒绝时保留手动输入。
定位中禁用坐标编辑与配置提交；离开页面或账号切换后丢弃迟到结果，不覆盖新账号表单。
参考：Tauri 官方 Geolocation 文档（https://v2.tauri.app/plugin/geolocation/）。
