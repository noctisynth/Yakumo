# 账号资料与合成运动工作流

文档编号：SPEC-008。状态：Active。更新：2026-10-15。

分三阶段交付并独立提交：账号资料、可复现生成与预览、显式提交和核对。
账号资料从当前用户接口独立读取，展示学校返回的全部非凭据字段，支持字段检索与嵌套值查看，
保留 null 和未知枚举；摘要展示头像、账号和学校。字段不齐时不猜测补全。令牌、密码、密钥、
设备证明与人脸照片等协议材料不进入页面；切换账号清空缓存，保留现有竞态防护。

生成器使用用户输入的种子、起始时间、位置、距离、时长与步数，离线生成固定一秒间隔闭环路线。
同输入生成相同数据，记录算法版本及合成来源；轨迹、总距离、配速、平均速度和分钟步数桶一致。
不把合成轨迹称为真实采集，不推断服务端合格。预览展示路线、指标、一致性及配置约束提示。

提交只能由用户明确操作，原生重新生成并校验，不信任前端载荷。绑定当前账号和预览标识，
使用现有同时间戳封包、双层表单与签名。原生重复防护覆盖并发和同一草稿，发送前持久记录意图；
超时、断网或未识别响应保留结果不确定，不自动重传。核对按已知记录标识读取详情，结合列表和
统计分别反馈；无标识时只能辅助查看列表，不宣称可靠自动对账或服务端幂等。
配置中必经点、围栏、人脸等未支持要求应阻止提交，不能伪造通过标记或设备环境证明。
本地校验和服务端判定分开呈现；真实提交不属于自动验收，验证使用合成夹具与模拟服务。
