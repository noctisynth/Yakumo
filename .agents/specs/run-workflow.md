# 账号资料与合成运动工作流

文档编号：SPEC-008。状态：Active。更新：2026-10-15。

分三阶段交付并独立提交：账号资料、可复现生成与预览、显式提交和核对。
账号资料从当前用户接口独立读取，展示学校返回的全部非凭据字段，支持字段检索与嵌套值查看，
保留 null 和未知枚举；摘要展示头像、账号和学校。字段不齐时不猜测补全。令牌、密码、密钥、
设备证明与人脸照片等协议材料不进入页面；切换账号清空缓存，保留现有竞态防护。

生成器使用用户输入的种子、起始时间、位置、距离、时长与步数，离线生成固定一秒间隔闭环路线。
同输入生成相同数据，记录算法版本及合成来源；轨迹、总距离、配速、平均速度和分钟步数桶一致。
不把合成轨迹称为真实采集，不推断服务端合格。预览展示路线、指标、一致性及配置约束提示。

提交只能由用户明确操作，原生重新生成并校验，不信任前端载荷。绑定当前账号和预览标识，
使用现有同时间戳封包、双层表单与签名。原生重复防护覆盖并发和同一草稿，发送前持久记录意图；
超时、断网或未识别响应保留结果不确定，不自动重传。核对按已知记录标识读取详情，结合列表和
统计分别反馈；无标识时只能辅助查看列表，不宣称可靠自动对账或服务端幂等。
配置中必经点、围栏、人脸等未支持要求应阻止提交，不能伪造通过标记或设备环境证明。
本地校验和服务端判定分开呈现；真实提交不属于自动验收，验证使用合成夹具与模拟服务。

首版提交范围：runType=1，必经点、围栏、中途人脸数组须明确为空，人脸开关、顺序检查、
速度范围检查和递增步数须明确关闭；缺失或未知均阻止提交。基础距离、时长及步数采用保守
区间检查，不复用尚未穷尽的历史时间谓词。首版仅允许最近七天已结束的数据；确认票据五分钟有效。
上传类型 0 来自历史合成实现的静态观察，不宣称枚举已经完整。兼容参数沿用已观察的公开版本。
合成点显式携带 f=true，顶层 f 为点数；这是替代客户端主动标记合成的产品选择，不声称执行了
Android 定位接口。isFaceStatus=0，不声称通过人脸；isValid=1 仅表示当前基础本地检查通过。
未知设备证明字段不添加，缺失原版流程可能导致学校拒绝或判定无效。

提交意图及回执复用加密账号容器，保存账号归属摘要、输入摘要、算法、合成来源、关联标识及回执，
不保存轨迹坐标。账号重新添加时仍以学校用户归属摘要防重，移除账号不抹除防重摘要与提交回执。
所有 unknown 提交会阻止该账号后续发送；只有学校详情中的 identify 精确匹配才能关联确认入库。
不提供将未知结果人工改成失败或强制重传的按钮。最多保存五千条意图，达到上限明确报错，
不静默丢弃历史来绕过防重。回执核对单独读取详情、有效列表当前日期页、统计及汇总；没有全量
列表扫描或自动重试，也不把未在本页找到等同于未入库。

资料页按个人信息、学籍信息、状态信息、系统标识与补充信息分组，中文名称优先，原字段名以名称后的次要文字显示，仍可检索。未确认枚举保留原值并提示含义待确认，不将状态 0/1 擅自译为业务结论。
无头像和图片加载失败时，资料页及账号菜单共用软件图标占位。头像写入仍缺上传契约及可用性证据，
本轮不开放修改入口，不能把静态回调中的成功提示当服务端成功依据。

用户于 2026-10-15 明确确认当前学校 userType=1 表示学生，isGraduation=0 表示未毕业。
展示同时支持上述数值及字符串形式；其他取值、null、布尔值不推导映射，继续保留原值。
该语义来源为用户确认，不冒充新增抓包或跨学校通用枚举。

用户确认 eduYear 的单位为年，资料页以“学制”显示并为数值补充“年”，不再展示单位待确认说明。

## 工作室分步、地图与预设

工作室使用 Stepperize 管理选点、参数、预览、确认四步，编辑参数即废弃旧预览和确认。真实地图仅作
地理参照和中心选点，不宣称圆形合成路线已匹配道路。地图加载由用户主动发起，保留署名及加载失败
提示，不自动定位、不预取离线瓦片；仅允许固定地图服务域名通过 CSP，不向地图发送账号或运动记录。
参数采用基准值和双端偏移区间，生成时一次抽样，记录实际种子与最终输入，可复现结果；不保证学校
判定或规避检查。距离可含小数，秒数、步数和圈数保留整数约束；派生速度和配速从最终距离时长计算。
开始时间以用户本地时间输入。学校规则和原生一致性检查仍为提交前置，不因随机范围绕过。
预设作为工作室二级页面，显式保存中心选点、基准值及偏移范围，按账号隔离存入现有加密容器。
不保存密码、令牌、历史运动起始时间或提交授权。应用预设仅填入参数，仍须生成、检查及显式确认。

预设每账号最多 30 条、容器总量最多 100 条；移除账号时同时删除其预设，确认文案明确说明，
提交回执与防重记录仍按原有规则保留。地图使用 WGS84 地理参照，不擅自转换为尚未确认的学校坐标系。
小数距离仍沿用已观察的上报精度量化，不为随机化改变既有上传字段和判定规则。
