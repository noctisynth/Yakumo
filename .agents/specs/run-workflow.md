# 账号资料与合成运动工作流

文档编号：SPEC-008。状态：Active。更新：2026-10-15。

分三阶段交付并独立提交：账号资料、可复现生成与预览、显式提交和核对。
账号资料从当前用户接口独立读取，展示学校返回的全部非凭据字段，支持字段检索与嵌套值查看，
保留 null 和未知枚举；摘要展示头像、账号和学校。字段不齐时不猜测补全。令牌、密码、密钥、
设备证明与人脸照片等协议材料不进入页面；切换账号清空缓存，保留现有竞态防护。

生成器使用用户输入的种子、起始时间、位置、距离、时长与步数，离线生成固定一秒间隔闭环路线。
同输入生成相同数据，记录算法版本及合成来源；轨迹、总距离、配速、平均速度和分钟步数桶一致。
不把合成轨迹称为真实采集，不推断服务端合格。预览展示路线、指标、一致性及配置约束提示。

提交只能由用户明确操作，原生重新生成并校验，不信任前端载荷。绑定当前账号和预览标识，
使用现有同时间戳封包、双层表单与签名。原生重复防护覆盖并发和同一草稿，发送前持久记录意图；
超时、断网或未识别响应保留结果不确定，不自动重传。核对按已知记录标识读取详情，结合列表和
统计分别反馈；无标识时只能辅助查看列表，不宣称可靠自动对账或服务端幂等。
配置中必经点、围栏、人脸等未支持要求应阻止提交，不能伪造通过标记或设备环境证明。
本地校验和服务端判定分开呈现；真实提交不属于自动验收，验证使用合成夹具与模拟服务。

首版提交范围：runType=1，必经点、围栏、中途人脸数组须明确为空，人脸开关、顺序检查、
速度范围检查和递增步数须明确关闭；缺失或未知均阻止提交。基础距离、时长及步数采用保守
区间检查，不复用尚未穷尽的历史时间谓词。首版仅允许最近七天已结束的数据；确认票据五分钟有效。
上传类型 0 来自历史合成实现的静态观察，不宣称枚举已经完整。兼容参数沿用已观察的公开版本。
合成点显式携带 f=true，顶层 f 为点数；这是替代客户端主动标记合成的产品选择，不声称执行了
Android 定位接口。isFaceStatus=1 表示受支持流程保留无异常的初始化状态，不表示完成人脸核验；
isValid=1 仅表示当前基础本地检查通过。
未知设备证明字段不添加，缺失原版流程可能导致学校拒绝或判定无效。

提交意图及回执复用加密账号容器，保存账号归属摘要、输入摘要、算法、合成来源、关联标识及回执，
不保存轨迹坐标。账号重新添加时仍以学校用户归属摘要防重，移除账号不抹除防重摘要与提交回执。
所有 unknown 提交会阻止该账号后续发送；只有学校详情中的 identify 精确匹配才能关联确认入库。
不提供将未知结果人工改成失败或强制重传的按钮。最多保存五千条意图，达到上限明确报错，
不静默丢弃历史来绕过防重。回执核对单独读取详情、有效列表当前日期页、统计及汇总；没有全量
列表扫描或自动重试，也不把未在本页找到等同于未入库。

资料页按个人信息、学籍信息、状态信息、系统标识与补充信息分组，中文名称优先，原字段名以名称后的次要文字显示，仍可检索。未确认枚举保留原值并提示含义待确认，不将状态 0/1 擅自译为业务结论。
无头像和图片加载失败时，资料页及账号菜单共用软件图标占位。头像写入仍缺上传契约及可用性证据，
本轮不开放修改入口，不能把静态回调中的成功提示当服务端成功依据。

用户于 2026-10-15 明确确认当前学校 userType=1 表示学生，isGraduation=0 表示未毕业。
展示同时支持上述数值及字符串形式；其他取值、null、布尔值不推导映射，继续保留原值。
该语义来源为用户确认，不冒充新增抓包或跨学校通用枚举。

用户确认 eduYear 的单位为年，资料页以“学制”显示并为数值补充“年”，不再展示单位待确认说明。

## 工作室分步、地图与预设

工作室使用 Stepperize 管理选点、参数、预览、确认四步，编辑参数即废弃旧预览和确认。真实地图仅作
地理参照和中心选点，不宣称圆形合成路线已匹配道路。地图加载由用户主动发起，保留署名及加载失败
提示，不自动定位、不预取离线瓦片；仅允许固定地图服务域名通过 CSP，不向地图发送账号或运动记录。
参数采用基准值和双端偏移区间，生成时一次抽样，记录实际种子与最终输入，可复现结果；不保证学校
判定或规避检查。距离可含小数，秒数、步数和圈数保留整数约束；派生速度和配速从最终距离时长计算。
开始时间以用户本地时间输入。学校规则和原生一致性检查仍为提交前置，不因随机范围绕过。
预设作为工作室二级页面，显式保存中心选点、基准值及偏移范围，按账号隔离存入现有加密容器。
不保存密码、令牌、历史运动起始时间或提交授权。应用预设仅填入参数，仍须生成、检查及显式确认。

预设每账号最多 30 条、容器总量最多 100 条；移除账号时同时删除其预设，确认文案明确说明，
提交回执与防重记录仍按原有规则保留。地图使用 WGS84 地理参照，不擅自转换为尚未确认的学校坐标系。
小数距离仍沿用已观察的上报精度量化，不为随机化改变既有上传字段和判定规则。

工作室起始时间使用 shadcn Calendar/Popover 与明确的时分秒输入，颜色随主题；保存预设入口放在
参数卡片右上方。选点阶段复用显式单次定位，点击前不读取位置，迟到结果不覆盖已修改或其他账号数据。
步骤按钮直接表达动作，去除“下一步”前缀；大盘刷新使用紧凑按钮并保留可访问名称。


## 多点路线补充

工作室保留中心环形，并提供多点路线：用户主动加载地图后按顺序选取 2–50 个坐标，
支持撤销、清空和显式获取当前位置加入路线。相邻点至少 1 米，路线总长 50 米至 30 公里。
选点按直线连接，不声称道路匹配，也不承诺学校审核结果；弯道由用户补点。
多点模式不使用圈数和中心位置偏移，沿选定折线到末端后原路折返，达到目标距离时结束。
种子控制沿线行进速度约 ±5% 的平滑变化，不将路线横向随机平移。
原生算法标记 waypoints-v1，保留 synthetic 来源，继续校验时间、步数、总距离及逐段速度。
预设加密保存全部路线点，旧预设无路线时继续按 circle-v1 处理；提交回执记录实际算法。
保存为预设使用主按钮，数据大盘刷新使用标准 sm 尺寸并与标题区域居中对齐。


地图交互补充：主动加载后启用滚轮与双指缩放，缩放按钮使用现有 Button 和主题图标，
移动端保持 44 像素触控目标，达到缩放上下限后禁用对应按钮。
移除可选 Leaflet 前缀，自定义署名保留清晰可见的 © OpenStreetMap contributors 及版权链接；
不折叠、不隐藏、不降低为不可辨识文字，主题使用实底卡片保证底图变化时可读。
依据：Leaflet 1.9.4 Control.Attribution 文档允许 prefix=false；OSMF Tile Usage Policy 第 2 节要求地图内清晰署名。


## 距离与配速驱动的参数（2026-10-15）

中心环形前端入口下线，新生成必须选择多点路线。旧环形预设可以读取参数，需重新选线后生成。
历史回执和底层旧算法兼容保留，不再提供新环形操作入口。地图署名紧贴右下角，保持可读。
开放路线原路往返，闭合路线按选点顺序循环，目标较短时途中截断；不缩放或平移路线来凑距离。
闭合语义修订记录为 waypoints-v2，避免与旧算法同名却改变相同输入的输出。
主参数为距离（公里）与配速（分秒/公里）；时长=距离×配速，估算步数=取整后的时长×估算步频/60。
默认步频 160 步/分钟只是合成假设，不能由距离和配速唯一推导，不代表用户实测或生理建议。
高级区可修改假设步频和双端偏移。每次使用新种子抽取距离、配速、步频后再计算派生值，
不对时长、步数和速度各自叠加独立误差；所有偏移置零时仍允许用户得到固定基准。
配速基准、步频和步频范围进入加密预设；实际抽取配速、估算步频进入生成输入与摘要，
原生校验它们与时间、步数一致，预览显示非实测来源；不对人工审核作通过承诺。
旧预设的时长/距离换算为配速基准，未提供估算步频时采用明确标示的默认假设。


显式定位成功后，新增路线点并将地图居中到该次坐标，缩放至少至 16 级；已有选点时同样聚焦。
视角请求独立于路线起点，不因起点未变化而失效；普通手动选点不会触发定位聚焦。
尚未加载地图时保留聚焦目标，待用户主动加载后定位视角，不因定位擅自加载底图。
工作室的预设列表入口使用主按钮。


工作室反馈贴近触发操作：定位位于地图卡片内、保存预设位于命名区域后、生成位于生成按钮前，
导出错误位于预览卡片导出区域下。错误按操作作用域隔离，不在步骤导航下集中展示。
保存为预设维持主操作样式并采用标准按钮尺寸；估算摘要标题为“预计运动数据”。


## 随机坐标轨迹修订

新路线算法 waypoints-v3 使用种子生成连续相关的行进量与坐标扰动；每秒坐标不再严格落在直线。
坐标浮动上限默认 0.8 米，可设 0–3 米，慢速时进一步缩小，避免位置跳动主导里程。
距离和瞬时速度基于扰动后的点重新计算，再校准沿线行进量；不缩放用户路线或伪造距离字段。
步数随连续行进量累计，分钟桶由点级累计值相减，末尾不足一分钟也计入。
新算法版本计入摘要；实际坐标浮动上限进入输入及加密预设。预览直接使用最终逐秒坐标，
隐藏选点直线覆盖层，显示实际浮动范围及局部放大入口，便于区分选线和上报轨迹。
FACT-003 的 a/o/t/s/c/e 与分钟桶语义保持不变；合成来源及模拟标记保持现状。
小幅浮动不能代替道路匹配，也不表示已完成真实设备、坐标系转换或审核验证。
公开参考：pretty-derby 的 routine.rs 固定版本 fb1d8d7d5588c06da0437ba0a5b5951e6265a586，
其对已有路线坐标逐点加噪声，不提供道路规划。源码头声明 AGPL-3.0-or-later；本次只研究设计思路，独立实现，未复制代码。


人脸状态修订：依据 FACT-004 及 EV-13/EV-14，isFaceStatus 表示运行期间是否保留正常初始状态，
不是人脸功能开关。只在学校明确关闭注册、开始、结束、中途人脸要求且 middleFaces 为空时，
本产品支持的无异常流程保留初始化值字符串 1；缺失、未知或开启要求时仍不产生提交票据。
这不表示完成过身份核验，也不修改真实人脸流程或服务器判定。错误备注后缀 0115 尚未解释。
