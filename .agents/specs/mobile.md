# 移动端布局与原生交付

文档编号：SPEC-009。状态：Active。更新：2026-10-15。
来源：用户本轮移动适配授权；实施清单：TASK-003；发布基线：SPEC-003。

窄屏及触屏使用大盘、记录、生成、我的四项固定底部导航；宽屏且具有精细指针与悬停能力时保留桌面侧栏。
手机横屏仍保留底栏，顶部与底部均预留系统安全区域。
“我的”集中展示账户切换、资料、学校配置和偏好设置；相关子页选中同一底部入口。
顶部保留品牌和当前账户入口，避免将完整桌面侧栏堆在手机内容上方。
底部预留安全区域与内容间距，触控区域至少 44 像素；未登录提示卡使用统一圆角。
移动布局不改变会话隔离、提交确认或防重语义。页面未适配的原生能力单独验证，不用窄屏截图代替。

Android 编译、安装与签名检查仅在 GitHub Actions 执行，本机不安装 SDK/NDK 或构建 Android。
原生能力和签名维护在实施前补充本规范，实际平台覆盖以 TASK-003 及验证记录为准。

Android 安全存储通过原生 Kotlin 桥接调用 Keystore，AES-GCM 包装随机主密钥，原有账号及回执
仍使用 ChaCha20-Poly1305 加密。包装密钥不可导出，损坏或遗失时明确报错，不生成替代密钥覆盖旧数据。
原生密钥方法不注册前端命令；仅 Rust 存储边界可取解包主密钥。Android 禁止应用备份，避免只恢复密文。
导出使用系统文档选择器，不申请全盘文件权限；桌面依赖按目标平台隔离。iOS 安全存储尚未实现，
不输出 iOS 安装包或将其标成已支持。

云端按锁定 CLI 初始化 Android 工程并应用版本控制中的原生及配置覆层。使用 SDK 36、NDK r28、
stable Rust，首批包含 arm64 与 x86_64，原生链接按 16 KB 页大小配置。学校 HTTP 入口继续显式确认。
跨平台预览仅生成 Actions 附件，不自动创建 Release；Android debug 附件明确标识为测试版本。
正式发布签名及安装验证在下一阶段完成后才纳入 Release 门槛。
原生桥接依据：https://v2.tauri.app/develop/plugins/develop-mobile/ 。

Android 发布采用长期 RSA-3072 自签证书，稳定证书指纹与公钥证书纳入公开源码；私钥及密码仅存
GitHub secrets。已有发布密钥不得自动替换；本机备份为加密 PKCS#12，密码另用当前 Windows 用户的
DPAPI 保护，不纳入 Git。三个 secret 名称为 ANDROID_KEY_BASE64、ANDROID_KEY_PASSWORD、ANDROID_KEY_ALIAS。
发布构建要求密钥齐全，签名身份与已登记指纹一致；校验 APK v2/v3、ZIP 与 ELF 16 KB 对齐及 AAB 签名。
云端 Android 模拟器执行安装、冷启动及同包覆盖安装；成功不代表所有厂商设备均已验证。
签名仅供可信 main 发布及手动验证工作流使用，外部 PR 不持有发布凭据。

正式发布须等待桌面矩阵与已验证签名 Android job 均成功，合并到统一附件集合后才执行发布。
手动验证仅上传 Actions 附件，不创建 Release，不消费 changeset，不自动合并发布分支。
Android 签名依据：https://v2.tauri.app/distribute/sign/android/ 。

Android 15+ 的边到边窗口由原生 WindowInsets 提供系统栏和刘海边距，前端使用原生值优先于 Web
safe-area 环境变量；同步系统栏图标深浅，键盘出现时收起底栏。此接口仅返回显示区域与键盘状态，
不返回密钥或账号材料。真实模拟器 UI 验证需滚动到可见控件再点击，避免将遮挡位置误判为页面失败。

## Android 地图连接反馈

地图继续使用固定 HTTPS 服务和系统缓存；Android WebView 保留原始 User-Agent，追加
Yakumo 应用名和公开项目联系地址，以满足地图服务的应用识别要求。未取得故障设备网络
响应前，不将白屏归因为权限、DNS、TLS 或服务端拒绝中的某一种。

地图单轮等待上限为 15 秒，不因连续加载事件重新延长；失败时保留视角、选点和重试入口。
区分离线、连接超时和底图加载失败；晚到的图片可以恢复显示，重试后忽略旧轮次事件。
不引入任意网络代理、不关闭证书校验、不自动切换未经确认的地图服务。
依据： https://operations.osmfoundation.org/policies/tiles/ 。
