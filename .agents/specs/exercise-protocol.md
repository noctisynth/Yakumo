# 运动协议离线适配

文档编号：SPEC-005。状态：Active。更新：2026-10-15。
依据：本轮用户授权；事实：FACT-002、FACT-003，EV-07、EV-08、EV-15。

纯 Rust 模块完成 GET 与普通 FormBody 两种签名，保留首值、末值、LF 和单次 URL 解码差异。
JSON 兼容原生对象排序、null 保留、整数边界与已观察浮点输出；Gson 对象 null 省略单独提供，
不自动改变原生输入。超界整数、非有限数及畸形百分号显式拒绝。
上传封包使用公开证书与上传公钥，追加 v，AES-ECB-PKCS7、RSA PKCS#1 v1.5 和双层表单编码。
配置 GET 使用单层查询编码，响应解密绑定同一不可变会话及时间戳。
模块只构造数据，不执行上传、不开放通用网络代理；密码学材料、canonical、令牌不得返回界面或日志。
头像复用同一签名实现。合成向量、七组原生 JSON、RSA 解密回读及错误边界离线验证后独立提交。
浮点临界舍入与 JNI 非法字符串不宣称穷尽兼容；不把通过本地回读当作服务端接受。
