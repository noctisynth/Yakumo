# 多账号与会话

文档编号：SPEC-004。状态：Active。更新：2026-10-15。
依据：用户授权首先实现多账号登录与切换；协议依据 FACT-002、EV-03。

## 范围与交互

桌面应用提供账号管理页及全局当前账号入口。支持添加、切换、重新登录及移除本地账号。
桌面当前账号以左侧栏底部账户卡片展示，点击向上展开账号列表、添加及管理入口；
移除顶部下拉框及重复的主导航入口。窄屏时卡片位于导航下方，菜单避让视口边缘。
卡片展示账号首字占位和学校，过期状态可见；菜单支持键盘、Escape 关闭及焦点返回。
头像读取依据 FACT-006：原生侧签名请求当前用户信息，从 imageRouteUrl 获取展示地址。
卡片与切换菜单使用 Avatar、AvatarImage、AvatarFallback；无头像或图片加载失败显示账号首字。
头像按账号加密缓存为受限大小的图片 data URL，原始地址及令牌不传给前端，不放宽 WebView 网络策略。
登录后读取头像；现有账号在首次读取当前账号及切换时补齐或更新头像，每个账号每次运行只尝试一次。
头像失败不阻止登录或切换，不自动循环重试；过期会话不发起头像请求。移除账号同时清理其缓存。
旧缓存缺少头像字段时兼容读取。仅展示 PNG、JPEG、GIF、WebP，拒绝 SVG 和非图片响应；
下载限制 256 KiB、禁止重定向。地址可为 HTTP/HTTPS 绝对或相对地址；拒绝用户信息和私网目标，
只对经过公网地址核对的主机建立图片连接。图片请求不携带 Bearer、Cookie、school 或 Referer。
原生账号存储上限调整为 16 MiB，容纳 20 个受限大小的加密头像。用户资料和头像均不进入日志。
本轮不上传头像、不修改资料、不将人脸采集照片当作展示头像。
同学校同服务端 user_id 重新登录更新既有会话，不产生重复项；不同账号独立保存。
移除当前账号后不自动选择其他账号。登录及切换成功后更新当前账号，失败保持原状态。
账号摘要包含不透明本地标识、学校、登录名、有效期和当前选择，不返回令牌、设备值或 appId。
前端仅在表单提交期间持有密码，提交后清空，不写入 Zustand、浏览器存储或日志。
普通浏览器预览显示原生功能不可用，不模拟真实登录成功。

## 协议边界

首期仅支持 schoolCode=swpu；固定学校地址，不提供任意 URL 代理。
按已验证新版协议获取动态 RSA 公钥，使用 PKCS#1 v1.5 加密密码后通过 Query 登录。
Basic 客户端兼容常量核对静态新版拦截器与 EV-03；它不是用户密码或私人会话。
每个账号生成独立随机设备标识，不读取机器硬件标识；不冒充原设备证明。
登录成功后获取原始 appId；任一步失败均不写入部分会话。
过期会话要求重新登录，不切换到已失效会话；无后台登录、无自动重试、不执行运动操作。
refresh_token 暂留原生会话供后续适配，不在未验证刷新合同前猜测请求参数。
已验证服务入口使用 HTTP，用户须在每次密码登录时确认传输风险；RSA 不能提供 HTTP
服务端身份验证，也不能保护之后的 Bearer 流量。拒绝重定向，限制超时及响应大小。
服务端正文、URL、Query、密码和令牌不进入错误消息或日志；返回固定结构化错误分类。

## 存储与一致性

Windows Credential Manager、macOS Keychain、Linux Secret Service 保存随机主密钥。
账号和令牌共同以 ChaCha20-Poly1305 加密存入应用私有数据区域；每次写入使用随机 nonce，
临时文件原子替换。密码不保存。密钥库不可用或密文损坏时明确失败，不降级明文或重置数据。
读取失败后保留原数据，允许重试；只有完整持久化成功才更新内存并返回新的账号快照。
原生操作串行执行，前端共享操作锁避免重复提交及迟到响应覆盖。每次请求使用所属账号会话。
桌面单实例插件阻止多个进程同时写入同一会话文件；不向前端开放该插件的系统操作权限。
移除只清理本地会话，不声称服务端令牌已撤销；不自动注销其他账号。

## 验收

覆盖双账号隔离、重复登录更新、切换及重启恢复、移除当前账号、存储失败不改变状态、
损坏密文拒绝读取、过期会话处理、RSA 和请求结构、错误脱敏与响应分类。
验证前端表单、全局账号状态、失败反馈和窄屏布局。真实账号链路测试单独授权和记录。
凭据库方案依据 [keyring 3 文档](https://docs.rs/keyring/3.6.3/keyring/)；
HTTP 客户端依据 [reqwest 文档](https://docs.rs/reqwest/0.12.28/reqwest/)；
密码加密与本地密文分别依据 [RSA 文档](https://docs.rs/rsa/0.9.10/rsa/)和
[ChaCha20Poly1305 文档](https://docs.rs/chacha20poly1305/0.10.1/chacha20poly1305/)。
本阶段不实现运动请求签名、学校设置、生成器或上传；这些继续由 TASK-001 跟踪。
