# 移动端适配与发布清单

文档编号：TASK-003。状态：Active。更新：2026-10-15。
来源：用户授权移动端底部导航、跨平台云端构建及 Android 签名；约束：GOV-001、SPEC-003。

本清单独立于桌面功能清单。首批移动目标为 Android；macOS、Windows、Linux 构建属于共享发布工作。
iOS 不因“跨平台”自动列为本轮必须交付的签名产物，后续再确认 Apple 账号、证书及分发方式。
本机不安装 Android SDK、NDK 或编译 Android；相关构建与安装验证使用 GitHub Actions。
每个阶段完成后独立 changeset 与 commit；允许推送 CI/CD 和配置必要 secrets，不自动合并发布分支。

## 阶段一：移动布局与交互

- [x] 修正未登录提示卡片的圆角，使其与页面视觉一致。
- [x] 窄屏使用固定底部导航，桌面保留侧栏；避免同时显示两套导航。
- [x] 为大盘、记录、生成及个人入口安排清晰层级，学校配置和偏好设置保留可发现的入口。
- [x] 账户切换、账号资料及登录入口在移动端仍易于访问，当前页面具有明确选中态。
- [x] 适配底部安全区域、触控尺寸与内容留白；360 像素浏览器布局不遮挡内容。
- [ ] 在 Android 运行环境验证真实软键盘下的表单及提交确认。
- [x] 检查登录、资料、大盘、记录及详情、配置、工作室和提交回执的窄屏布局。
- [x] 验证深浅主题、未登录、登录过期、账号切换及迟到响应，不引入页面横向溢出。
- [x] 更新设计与验证记录，创建本阶段 changeset 并 commit。

## 阶段二：移动原生能力与云端产物

- [ ] 将桌面专用依赖与启动逻辑按平台隔离，避免 Android 编译引入桌面服务。
- [ ] 接入 Android 系统安全密钥存储，保持会话与提交回执加密；不降级为明文或模拟密钥库。
- [ ] 明确 Android 最低与目标系统、CPU 架构及构建工具版本，记录实际云端构建结果。
- [ ] 初始化可复现 Android 工程，检查包标识、网络权限、学校 HTTP 兼容边界与应用图标。
- [ ] 检查移动端导出预览、系统返回和应用重启后的会话及防重记录；不可用能力明确反馈。
- [ ] 在 GitHub Actions 配置 Android 构建，保存可安装 APK 和适用的分发产物。
- [ ] 发布流程保留 macOS、Windows、Linux 桌面矩阵，并将 Android 纳入产物汇集及校验清单。
- [ ] 提供云端验证入口，不消费 changeset 或为测试擅自创建正式 Release。
- [ ] 检查实际 Actions 结果并修复失败；创建本阶段 changeset 并 commit，不合并发布分支。

## 阶段三：Android 签名与安装验收

- [ ] 检查现有签名凭据，已有正式密钥不得静默替换；没有时生成长期发布密钥。
- [ ] 将签名材料和密码保存为 GitHub Actions secrets，不进入源码、日志或公开附件。
- [ ] Release 构建使用稳定签名身份，确保后续版本可覆盖升级，不使用临时 debug 证书冒充发布签名。
- [ ] 验证 APK 签名及证书指纹、所需签名方案和现代 Android 兼容性，失败时停止发布。
- [ ] 核对包对齐、SDK 要求及原生库页大小兼容等安装前提，签名通过不等同于所有系统都能安装。
- [ ] 在云端模拟器安装、冷启动及验证覆盖安装；设备或模拟器未覆盖的部分单独注明。
- [ ] 签名与构建凭据仅用于可信工作流；外部 PR 不获得发布 secrets。
- [ ] 所有目标产物通过检查后才允许汇集发布；不自动合并发布分支。
- [ ] 更新签名维护、密钥备份与验证文档，创建本阶段 changeset 并 commit。

## 验收口径

前端响应式、Android 原生编译、APK 签名、安装启动和账号业务分别记录结果。
仅生成移动图标、浏览器窄屏预览或产出 APK，不足以勾选 Android 已完整可用。
真实学校业务验证继续使用独立授权范围，不在云端构建中自动登录或提交运动数据。
