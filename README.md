# 八云爱 · Yakumo

<!-- 文档编号：README-001。 -->

**把时间，还给自己。**

八云爱是一款跨平台的跑步数据客户端。连接学校账号，查看运动进度与记录，在地图上规划路线，生成、预览并确认提交跑步数据。

[下载安装](https://github.com/noctisynth/Yakumo/releases/latest) · [反馈问题](https://github.com/noctisynth/Yakumo/issues) · [参与贡献](https://github.com/noctisynth/Yakumo/blob/main/CONTRIBUTING.md)

## 你可以做什么

- **查看运动进度**：在数据大盘查看累计、本周与学期里程，了解运动记录和统计变化。
- **管理学校账号**：添加、切换和移除多个账号，查看个人资料与更换头像。
- **检索运动记录**：按状态和日期筛选，查看每次运动的详情与学校判定。
- **使用生成工作室**：在地图上逐点规划路线，设置距离与配速，预览轨迹和数据，并保存为预设。
- **确认后再提交**：自动检查数据与学校要求，由你确认发送；遇到结果不确定的情况，先核对记录，避免重复提交。

支持深色与浅色主题，桌面侧栏和手机底部导航分别适配不同屏幕。

## 下载与安装

前往 [GitHub Releases](https://github.com/noctisynth/Yakumo/releases/latest)，选择适合设备的安装包。

| 设备 | 下载文件 |
|---|---|
| Windows x64 | `.exe` 安装程序 |
| Linux x64 | `.AppImage` 或 `.deb` |
| macOS Apple Silicon | `aarch64` / `arm64` 对应的 `.dmg` |
| macOS Intel | `x64` / `x86_64` 对应的 `.dmg` |
| Android | `.apk` 安装包 |

Android 的 `.aab` 用于应用分发，直接安装请选择 `.apk`。iPhone 和 iPad 目前没有安装包。

带更新能力的客户端会在打开时检查新版本，也可在“偏好设置 → 应用更新”中检查、查看说明和下载。
下载后需要确认安装；Android 还会请求系统安装来源权限及安装确认。更新可能关闭应用，重新打开后
可查看实际版本。旧客户端需先手动安装一次带更新能力的版本；若提示尚未配置更新签名，继续使用发布页下载。
检查和下载使用公开镜像与官方备用地址，所有更新必须通过签名、版本和平台检查。公共镜像可用性
随网络变化，缓存可能延迟发现更新；签名错误时应停止并反馈，不要绕过验证。

Windows 安装程序尚无商业代码签名，macOS 应用尚未经 Apple 公证，系统可能显示安全提示。请确认文件来自本项目发布页；附件同时提供 SHA-256 校验文件。

## 开始使用

1. 打开应用，添加学校账号。当前适配 **西南石油大学**。
2. 登录后进入数据大盘，查看运动进度；在“运动记录”中检索详情。
3. 打开“生成工作室”，依次完成地图选点、距离与节奏、检查预览和确认提交。已有预设可重复使用。
4. 提交后查看学校返回的结果，再通过运动记录和大盘核对。

工作室生成的是**合成数据**，不代表设备实际采集的运动。学校是否接收、是否判为有效及是否计入统计，由学校服务决定；客户端不能保证结果。学校规则检查未通过时，会阻止发送并说明原因。

## 隐私与权限

不内置广告或无关遥测，不保存密码。账号会话在本机加密保存，由系统安全存储保护；切换账号时隔离各账号的数据。

只有点击“获取当前位置”后，才会请求位置权限并定位。地图加载会向底图服务请求当前视野的地图图片；默认使用天地图，加载失败时可以切换备用底图。

学校登录服务使用未加密连接，请在可信网络登录，并留意应用内的传输风险提示。Linux 用户需要可用且已解锁的系统密钥库。

## 遇到问题

- **地图一直加载或空白**：等待页面给出错误提示后重试，或切换底图、检查网络连接。
- **提交结果不确定**：先查看运动记录及统计，避免重复发送。
- **其他问题**：在 [Issues](https://github.com/noctisynth/Yakumo/issues) 提供应用版本、操作系统、复现步骤和经过遮挡的截图。请隐藏姓名、学号、位置等个人信息，不要上传密码或登录凭据。

开发环境、构建命令和协作流程见[贡献者指南](https://github.com/noctisynth/Yakumo/blob/main/CONTRIBUTING.md)。

项目命名灵感来自东方 Project 的《yakumo ai!》跑酷游戏，应用角色插画为非官方形象。
